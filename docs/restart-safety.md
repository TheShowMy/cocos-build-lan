# 退出与任务清理

npm 只负责下次启动时选择版本，应用不自行更新或切换安装目录。

Q/Ctrl+C 显示退出确认，默认取消。确认后先关闭新任务入口，再取消队列、停止受控任务进程、等待活动操作释放、持久化状态与日志，最后恢复终端并退出。等待最多 10 秒，不在任务仍运行时变更引擎或工作目录。

所有任务子进程使用 `process::Command`：Windows 下先以挂起状态创建，再加入设置了 `KILL_ON_JOB_CLOSE` 的 Job Object，然后恢复执行，避免子进程在纳管前派生。浏览器打开不加入任务 Job。Cocos、Git、uv/Python、Node 与 Rust 混淆工作进程均适用。

退出信号或终端关闭也清理受控子进程；强制结束进程时 Job 句柄关闭负责回收。下次启动将残留运行态恢复为失败状态。不能根据进程名终止其他用户进程。

验收覆盖：取消退出保持任务运行、确认退出取消活动/排队任务、慢任务不阻止退出、无残留子进程、日志刷盘、重复启动和异常退出恢复。
