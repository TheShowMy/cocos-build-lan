# Web 打包页与参数规则验收

验收日期：2026-10-13。保留现有 npm/TUI 重构，版本仍为 `0.2.0`；本轮没有发布 npm、提交或推送 Git。

## 实现范围

- `identifier` 保存时统一小写，默认值、选项、组值和预设执行相同校验；拒绝非法字符、规范化重复选项及占位符冲突。
- 用户参数支持 `${param.key}`；英文标识、布尔提供大小写短引用。`build_mode=prod` 输出 `prod/PROD`，不经过旧构建模式枚举。替换为单次解析，未知引用保留。
- 共用占位符说明、复制入口及锤子 SVG favicon。
- 分支持久缓存、手动刷新、请求共享、失败保留旧列表；记住任务组与当前标签页的跨组勾选。
- 常驻组内工具栏与全局串行队列区；服务状态明确区分当前、等待、取消，阻止重复提交。
- 组参数草稿保护，保存、放弃或留在当前页；保存失败保留草稿，成功回显规范化结果。
- 修复停止队列不能及时中断准备阶段的问题，统一取消整项任务并由受控进程释放子进程树。

## 浏览器与实际进程验收

使用独立测试数据目录 `target/web-acceptance-20261013`，端口 `49344`，两个组、四个任务及本地 Git 仓库。未写入用户正式应用数据。

- 分支缓存跨组、页面导航及刷新后仍可用；新增分支只有手动刷新后出现。仓库临时不可用时保留旧列表，测试结束已恢复仓库。
- 组内操作只针对本组，另一组勾选保留；全局合计与组勾选数一致，刷新后恢复。
- 工具栏勾选前后位置和高度不变。390 像素窄屏下文档宽度为 381，无整页横向溢出。
- `Japan_Release` 保存后显示 `japan_release`；非法 `invalid_1` 拒绝保存并保留草稿；`prod/PROD` 重复选项在弹窗内报错。
- 未保存时禁用相关启动/准备操作；跨组及页面导航触发保存、放弃、留在当前页。重复点击当前组保留草稿且不弹出切换提示。保存并继续成功后才切换组。
- 动态说明包含 `${BUILD_MODE}` 和 `${ENABLE_PAY}`；favicon 已加载，最终页面检查无浏览器控制台错误。
- 全局队列真实显示正在执行的任务、所属组及等待任务；停止确认的取消按钮保持任务运行，确认操作停止整个队列。

使用真实 Python 准备脚本等待 120 秒测试取消，不执行真实 Cocos 打包。提交 `t1,t3` 后，状态为 `t1` 活动、`t3` 等待；重复启动返回 HTTP 409。停止后约 **0.141 秒**恢复空闲，准备脚本进程退出，`t1/t3` 为已取消，未提交的 `t2/t4` 保持待执行，活动/等待/取消标志清空。

实际传给准备脚本的值为 `--mode prod --mode_upper PROD --pay FALSE --channel japan_test`，同时自动注入 `--project_path`。结果记录在测试目录的 `queue-result.json`。
