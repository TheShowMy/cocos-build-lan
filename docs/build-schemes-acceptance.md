# 构建方案、内置版本与提示计时验收

日期：2026-10-13。代码版本仍为 0.2.1，本轮未发布 npm。保留已有 npm/TUI、Web 参数优化和左右独立滚动实现。

## 实现

- 每组默认 pro/test，最多五项；显式保存分支、全部参数和本组任务勾选，支持另存、重命名、删除及切换前保存/放弃/取消。
- 当前关联 ID 按站点/工具/组保存在浏览器，方案内容保存在服务端；首次未关联，删除当前方案保留当前配置。部分参数预设不覆盖完整方案。
- 方案接口校验数量、名称、参数和任务归属；应用/保存锁定空闲队列。相关配置修改串行化，设置使用临时文件写入、刷盘并替换，失败不提交组参数和方案。
- 内置 version 固定为必填版本类型。自定义 version 类型允许可选空值，字符串保留前导零；统一前缀删除末段，与资源仓库分支使用同一函数。
- 服务端提供共用占位符目录，设置页用户参数与只读内置区分开。独立准备运行不使用隐藏项目版本作为占位符回退。
- App 生命周期管理约 3.6 秒提示，唯一消息 ID 防止旧计时清除新消息。
