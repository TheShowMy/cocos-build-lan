## 浏览器实测

- 首次自动关联首项；选择非首项 pro 后刷新，仍选中 pro，恢复保存的任务勾选。
- 在未保存的版本草稿 `09.4.2` 下快速勾选/取消，接口读取确认只有任务 ID 改变，组及方案版本仍为旧值。显式保存后再切换回来恢复新版本。
- 切方案遇到参数草稿显示保存/放弃/取消；取消保留草稿。局部预设更新当前方案参数，分支与勾选保持。
- 编辑方案禁用参数与任务勾选；取消撤销改名。新增、重命名批量保存；删除当前项切换剩余首项；最后一项删除按钮和第六项新增按钮禁用。
- 重复名称保存失败保留编辑区及名称草稿，修正后保存成功。
- 在隔离配置路径制造写盘失败，出现“勾选未保存”，本地选择保留，切方案出现未保存对话框；恢复配置路径后重试成功。
- 勾选后立即切到设置页，后台仍保存成功。刷新后全局清空，接口确认已访问的两个任务组各自当前方案的 taskIds 均为空，其他方案不变。
- `?` 可通过 Enter 打开、Escape 关闭并归还焦点；版本前缀预览位于浮层，未增加网格行高度。
- 1440×900 下五参数/五方案卡片约 258px 高，无整页横向溢出。1100×600 右侧滚到底（scrollTop 1546）时，左栏全局区位置不变，页面 scrollTop 保持 0。
